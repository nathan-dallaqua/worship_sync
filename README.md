# Worship Sync

Aplicativo para criação e gerenciamento de escalas de grupos de louvor.

## Funcionalidades

- **Dashboard** — visão geral com próximas escalas e estatísticas
- **Escalas** — crie, visualize e gerencie escalas com equipe e repertório
- **Músicas** — biblioteca de músicas com letras, cifras e notas
- **Perfil** — gerencie membros do grupo e configurações

## Perfis de acesso

- **Admin** — cria escalas, gerencia membros e repertório
- **Membro** — visualiza escalas, confirma presença e acessa músicas

## Tecnologias

- [Expo](https://expo.dev) + [Expo Router](https://docs.expo.dev/router/introduction/)
- React Native
- AsyncStorage para persistência local

## Rodando o projeto

```bash
npm install
npx expo start
```
